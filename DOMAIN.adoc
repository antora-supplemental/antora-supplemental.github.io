## Registry OAuth / Better Auth (Netlify env)

Set after the custom domain is attached in Netlify:

```
BETTER_AUTH_URL=https://registry.antora-supplemental.org
BETTER_AUTH_TRUSTED_ORIGINS=https://registry.antora-supplemental.org
```

Update each OAuth app’s callback to:

`https://registry.antora-supplemental.org/api/auth/callback/<provider>`

(providers: `github`, `gitlab`, `google`, `microsoft`, `apple` as configured)
