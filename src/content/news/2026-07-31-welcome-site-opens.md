The organization needed a front door that was not a README dump and not the docs hub. That door is [antora-supplemental.org](https://antora-supplemental.org/): brand first, philosophy next, notable projects after that, and a clear path into the documentation site and the ecosystem registry.

Today the site gains a news feed. Releases, hard product calls, and the occasional philosophical piece — written to be read, not to fluff a changelog. The feed lives at [/news/](/news/). The homepage surfaces the latest. Project manuals stay in the docs hub and per-repo sites. News is for the big picture.

Light and dark follow system preference, with a header toggle when you want to override. Same green brand language as the rest of the org chrome. Built with Astro so shared layout stays DRY and deploy cannot forget a folder.

If you are new here: start with philosophy, skim the contributions list, then open the [docs](https://docs.antora-supplemental.org/) or the [registry](https://registry.antora-supplemental.org/). If you already ship Antora on GitHub, watch this feed for what lands next.
