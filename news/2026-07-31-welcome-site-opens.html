The welcome site is live — and it has a news desk

The organization needed a front door that was not a README dump and not the docs hub. That door is antora-supplemental.github.io: brand first, philosophy next, notable projects after that, and a clear path into the Antora documentation site under /docs/.

Today the site gains a news feed. Releases, hard product calls, and the occasional philosophical piece — written to be read, not to fluff a changelog. The feed lives at /news/. The homepage surfaces the latest. Project manuals stay in the docs hub and per-repo sites. News is for the big picture.

Light and dark follow system preference, with a header toggle when you want to override. Same green brand language as the rest of the org chrome. Static HTML, no build step for the welcome page — because the welcome page should stay cheap to edit.

If you are new here: start with philosophy, skim the contributions list, then open the docs. If you already ship Antora on GitHub, watch this feed for what lands next — Actions, themes, serve, incremental rebuilds, and the rest of the supplemental surface.
